# Contributing to Epix

Thanks for wanting to help out. Contributions are welcome — whether that's adding games, fixing bugs, or improving the site.

## Ways to Contribute

- **Add a game** — suggest or add a new unblocked game
- **Fix a broken game** — report or fix a game that no longer works
- **UI/UX improvements** — better design, accessibility, mobile support
- **Bug fixes** — anything broken on the site itself

---

## Adding a Game

This is the most common contribution. Before submitting:

- Make sure the game actually works and loads properly
- Make sure it isn't already on the site
- Write a real description (one or two sentences on what the game is and why it's fun — not just "its cool")
- Include a working thumbnail/cover image if possible
- Assign it to the correct category (Arcade, Driving, Horror, Idle, Platformer, Puzzle, Rhythm, Runner, Shooter, etc.)

---

## Getting Started

1. Fork the repo
2. Create a branch: `git checkout -b add/game-name` or `git checkout -b fix/issue-description`
3. Make your changes
4. Test locally — make sure nothing is broken
5. Open a pull request with a clear title and description of what you changed

---

## Pull Request Guidelines

- Keep PRs focused — one game or one fix per PR
- Use a descriptive title, e.g. `Add: Slope` or `Fix: OvO 2 embed broken`
- If you're fixing a bug, mention what caused it and how you fixed it
- Don't submit PRs with placeholder descriptions or broken links

---

## Reporting a Broken Game

Open an issue with:
- The game name
- What's broken (won't load, wrong URL, crashes, etc.)
- A working alternative link if you have one

---

## Code Style

- Keep it consistent with the existing codebase
- No unnecessary dependencies
- Don't break mobile layout

---

## Security Issues

Do **not** open public issues for security vulnerabilities. See [SECURITY.md](./SECURITY.md) for how to report them privately.
